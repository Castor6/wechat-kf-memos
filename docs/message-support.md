# 消息获取与标签规则

依据：2026-09-19 在 Chrome 核对的[独立微信客服接收消息文档](https://kf.weixin.qq.com/api/doc/path/94745)。实现范围是独立客服官方 API 的收件、素材下载及接入所需只读元数据；不依赖个人微信登录、Hook、爬聊天数据库或企业微信自建应用。

## 消息覆盖

| 官方类型 | Memos 中的结果 | 边界 |
|---|---|---|
| text | 字面正文；显式标签独立提取 | 不执行原文 HTML/Markdown |
| image / voice / video / file | 下载素材，关联私有笔记；保留下载头提供的文件名 | 无文件名时生成；语音不转写、图片不 OCR |
| location | 地点、地址、经纬度 | 不调用地图 API |
| miniprogram | 标题、AppID、页面路径、缩略图附件 | 不获取小程序内部页面 |
| channels_shop_product | 商品 ID、标题、售价（分）、店铺及图片地址 | URL 原样作为文本保留，不抓取远程网页 |
| channels_shop_order | 订单 ID、商品名称、金额描述、状态、图片地址 | 不查询或操作订单 |
| merged_msg | 按原顺序保留发送人、时间及各条消息；嵌套媒体同样上传 | 递归展开 8 层，更深部分保留原始 JSON |
| channels | 视频号类型、昵称、标题 | API 没有提供的视频本体无法下载 |
| note | 不创建 Memos 笔记；启用回执时直接回复失败原因 | 微信接口仅提供类型，不提供笔记正文 |
| event | 授权发送者的会话进入、发送失败、撤回事件进入独立事件表 | 不生成空笔记；撤回不自动删除已剪藏内容 |
| link（兼容） | 标题、摘要、链接 | 独立文档当前列表未列出此类型；保留兼容解析，顶层独立卡片尚待真机验收；已保存聊天记录中的链接条目 |
| 未知类型 / 新增字段 | 保留返回 JSON | 不静默丢弃，不保证未知媒体字段能自动下载 |

已知类型不向正文追加接口辅助字段（例如 mentioned_list、menu_id）或“其他字段”JSON。异常结构、无法解析的合并条目保留原文。JSON 代码块使用动态长度围栏，内容中的围栏或 `#` 不会逃逸成笔记结构或标签。

微信客服只能拿到你主动发送给它、且官方允许返回的内容。它不能读取你其他聊天，也不能补取接口未返回的原文。超出微信大小限制的媒体可能只返回文字提示：官方目前列出图片/语音 2 MB、视频 10 MB、文件 20 MB。素材有有效期，桥接器不能保证微信过期后的附件恢复。

## 标签规则

- 每篇默认带 `#微信剪藏`，通过 `DEFAULT_TAGS` 配置（逗号分隔、不写 `#`，可以留空）。
- 顶层文字中的独立 `#标签` 会提取、去重并作为笔记标签，例如 `想继续研究 #AI #工作/项目`。
- 顶层文字中用于分类的 `#标签` 从正文移除；URL 片段、代码和历史聊天中的井号按原文保留。
- `MEMOS_TAG_MODE=explicit` 使用定制版 Memos 的 `tags` + `explicitTags`，正文不追加标签。创建时设置 explicitTags，更新时 updateMask 包含 tags。上游兼容模式 `markdown` 仅在文末追加标签行，不添加标题或来源。
- 支持中文、Unicode 字母/数字/符号、emoji、`_`、`-`、`/`、`&`；最多 100 个 Unicode 码点。桥接器排除 HTML 尖括号。标签前使用空格或标点；URL 片段、转义井号、代码块和标题不是标签。
- 合并转发记录额外加 `#微信聊天记录`，通过 `CHAT_RECORD_TAG` 配置。记录内别人的标签和卡片标题不自动变成自己的分类。
- 分开发送一条 `#标签` 会成为独立笔记，**不会修改上一条聊天记录**。跨消息关联不在当前规则中。

示例：发送 `今晚回顾 #读书 #AI` → `#微信剪藏 #读书 #AI`；合并转发聊天记录 → `#微信剪藏 #微信聊天记录`。

## 事件和接入信息

事件与消息游标同事务保存，重复事件去重。事件保留 30 天，在下一次拉取提交时清理；短期发送凭证 `welcome_code` 不归档。事件不触发欢迎语或删除笔记；发送失败事件会更新对应回执的投递状态。

只读元数据接口：客服账号列表（自动分页）、白名单客户基础信息及最近进入会话的上下文。客户基础信息受官方最近 48 小时交互等限制，第三方/账号权限还可能限制部分字段，返回结果不等于所有账号都有权限。

```sh
# 文件必须不存在；目录自行选择可信的本地目录。导出权限为 600。
uv run --env-file .env python -m wechat_kf_memos export-info --output data/account-info.json
uv run --env-file .env python -m wechat_kf_memos export-events --output data/events.json
```

这些导出仅在本机保存，不向控制台打印内容、不自动授权发送者、不上传 Memos。`export-info` 只查询白名单中的客户；尚未设置白名单时仅导出客服列表，便于找到 open_kfid。

“获取企业状态信息”文档指向企业授权信息接口，属于服务商授权模式；当前独立账号方案没有虚构一个企业状态接口。服务商代管、账号增删改、订单操作不属于本项目的剪藏数据获取范围。

## 正文与个人空间（2026-09-19）

正文不添加“微信剪藏”标题、来源、转发时间或接口辅助字段。普通文字仅保留消息内容；合并记录保留原聊天标题、发送人、时间及消息顺序，不额外增加整篇剪藏的头部信息。

当前定制版部署使用 `MEMOS_TAG_MODE=explicit`。Memos 的 `space` 为空表示默认“个人”空间，服务不发送 `X-Memos-Space` 请求头，因此不会跟随浏览器切换空间。接口核对依据：定制版 `memo_service.proto`、`memo_service.go`、`personal_space.go` 及路由空间上下文；已通过本机真实 API 与生产测试笔记回读验证。
