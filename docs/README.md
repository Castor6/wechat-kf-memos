## 记录方式

Task 使用 TASK-YYYYMMDD-短主题 编号，文件名保持稳定。助手在讨论时整理目标和验收标准，完成本次工作后记录实现、验证事实和未覆盖范围；相关小修可共用任务。

记录是带日期的事实，不是实时看板。模板和索引不填写实时 CI、合并或部署状态。具体提交的 CI 结果可以带运行链接作为历史证据；后续进展查询 PR、Actions、Release 或私有运维记录，不为追赶外部进展反复提交文档。

续接时只读取相关任务，按需核对相关证据并补充新日期；保留历史事实，明确旧限制是否已解决。长期结论提炼到需求、接口或模块文档。任务索引只存编号、标题、关键词和详情链接；过长时按年份归档到 tasks/archive/YYYY/INDEX.md，保留可检索入口。

微信客服已选择内置到 Memos；长期功能和迁移主任务归入 ~/Code/memos，本仓库保留历史、必要旧服务维护及移交记录，互链任务与 PR。原始聊天、日志、截图、账号、真实地址、配置和备份不进入公开记录。~/Code/... 项目路径按用户明确要求保留。
