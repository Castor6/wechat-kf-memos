# 安全与提交范围

仓库允许公开；私人运行资料与代码分开保管。公开不代表服务入口公开授权：剪藏和回执均仅限配置的本人白名单。

## 不得提交

- 微信 Secret、回调 Token/AESKey、Memos PAT、账号密码、SSH 私钥及证书私钥。
- 真实企业/客服/客户标识、生产地址、本机个人路径、绑定口令、原始聊天、截图、导出、运行日志。
- `.env` 及其历史副本、SQLite/WAL、附件、备份、私有运维目录。

`.env.example` 仅保留空凭据与通用地址；`.gitignore` 排除常见私有路径及备份格式。但忽略规则不保护已经进入 Git 的文件，不能代替暂存区检查。

测试使用合成消息；腾讯公开算法向量保留出处，其示例 Token、AESKey 和接收方不是生产配置。依赖锁文件中的哈希与公开包地址不是秘密。

## 后续维护

每次提交检查 `git diff --cached --stat`、`git diff --cached --check`，并审查实际暂存内容。新增样例必须合成；不要复制真实失败请求。扫描与诊断输出只显示路径/类别，不显示密钥。涉及历史提交时也检查历史，不能只删工作区文件。

凭据只保存在受限环境文件（600），不开启带查询参数的回调访问日志，不打印远端响应和令牌 URL。若敏感值已被输出或推送，应先撤销/轮换，再处理历史；删除文件不能让已泄露凭据重新安全。
