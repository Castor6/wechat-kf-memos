复现真实 API 合约测试（需本机已有兼容 Memos 源码和 Go）：

```sh
# 在 Memos 源码目录执行；输出写到自己指定的临时路径。
go build -o /tmp/wechat-kf-memos-test-server ./cmd/memos
# 回到本项目：
TEST_MEMOS_BINARY=/tmp/wechat-kf-memos-test-server uv run pytest -q
uv run ruff check .
```

不传 `TEST_MEMOS_BINARY` 时只运行单元/模拟测试，真实 API 测试明确跳过。测试不接受远程 Memos URL，避免误写线上。
