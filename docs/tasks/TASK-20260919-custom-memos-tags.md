# TASK-20260919-custom-memos-tags：定制 Memos 独立标签与纯净正文

- 记录日期：2026-09-19（按既有证据整理的历史事实）
- 模块与关键词：Memos、标签、个人空间、正文、0.1.1
- 来源：本项目既有模块文档、开发验证记录及本次项目讨论

## 背景与目标

用户接受默认个人空间，要求正文只有发送的实际内容；标签在定制 Memos 顶部独立展示，去掉自动标题、来源、转发时间和辅助接口 JSON。

## 验收标准与事实

- [x] explicit 模式创建传 tags/explicitTags，更新掩码包含 tags，正文不追加分类标签。
- [x] 顶层分类 #tag 从正文移除；URL 片段、代码和历史聊天内容保留。
- [x] 不发送 X-Memos-Space 请求头，默认个人空间；PRIVATE 不变。
- [x] 聊天记录保留原有标题、说话人、时间与顺序，不额外添加整篇剪藏元信息。

## 实现与验证事实

2026-09-19 核对定制 Memos 的 proto、服务实现及空间上下文，完成 0.1.1 适配。41 项测试通过，包括两个本机临时真实 Memos API 标签模式测试。该次上线前备份配置、队列和旧安装包，并经 API 备份、修正指定测试笔记。

生产 API 回读与 Chrome 检查确认个人空间、PRIVATE、纯正文及独立标签；没有改动 Memos 源码、证书或数据库。本记录整理时没有再次调用生产接口或重跑这些测试。

## 边界与长期文档

适配目标为个人版 Memos 0.2.0（官方 0.30.0 源码基线），不保证任意上游版本兼容。接口后续变化按两个项目 AGENTS 中的联动规则处理。见[接口约定](../memos-contract.md)。
